## 🚀 How to Download the Practice Files

You can download the practice datasets, Excel workbooks, and raw CSV files used in the videos in two ways:

### Method 1: Download All Files At Once (Recommended)
1. Scroll to the top of this page.
2. Click the green **`< > Code`** button on the right side.
3. Select **Download ZIP** from the dropdown menu.
4. Extract the folder on your computer to access all files.

### Method 2: Download a Specific File
1. Click on any file name listed in the folder above.
2. Once the file page opens, right-click the **Download** or **Raw** button.
3. Select **Save Link As...** to save the exact file straight to your machine.
